# Moodie HTML · Grok 小脸

一个会"活"的动画小表情——GrokBot 表情动作实验室的浏览器单文件版。纯 HTML/CSS/JS，零依赖、无图片资源，**双击打开 `moodie.html` 即玩**。

数据与动画核心移植自 [zhulin025/LaoA-GrokBot](https://github.com/zhulin025/LaoA-GrokBot)，在此之上做了**全面 UI 重设计 + 动画增强**，形成自己的特色。

---

## 🌟 咱的特色（原版没有的）

### 🎨 ins 名片渐变 UI
- 页面背景：ins 个人名片经典渐变（黄→橙→粉→紫→蓝 135° 斜向）
- 半透明白卡面板 + 毛玻璃 + 柔和阴影，标题/页脚白字适配渐变

### 🃏 卡片堆叠交互（澎湃 OS / 微信照片堆叠风）
- 4 张卡片叠放，向右下阶梯错位 + 微旋转，每张卡边缘可见
- **单击**露边卡 → 丝滑提到最前
- **双击** → 循环切换下一张（0→1→2→3 无限轮转）
- **拖动**卡片左右甩 → 跟随手部旋转倾斜，松手切下一张
- 三种切换风格：**翻面**（3D flip）/ **旋转**（rotate）/ **弹出**（pop）

### 🌀 增强动画系统（比原版更"活"）
- **身体弹簧**：整颗球 y/旋转/缩放四维弹簧驱动，切换时 Q 弹回弹
- **呼吸浮动**：身体永远在轻微起伏（体积守恒），生命感
- **平滑曲线眼睛**：原版是直线多边形，咱改成 Catmull-Rom 平滑曲线
- **39 状态持续循环动作**：搜索/雷达眼睛扫描、睡觉起伏、兴奋持续弹跳、轨道旋转、工作抖动…状态存续期间一直动（原版只有切换时的一次性动画）
- **25 表情搭配动作**：每个表情切换时配套弹跳/倾斜/压扁/旋转
- **点击反应**：点击身体触发状态专属反应（bounce/squash/tilt/spin）

## ✨ 功能

### 🎭 表情与状态
- **25 套原版表情**（Grok 原始坐标数据，逐点 morph 过渡）
- **39 种状态动作**（4 组分类）：睡眠/唤醒/待机/倾听/思考/搜索/工作/兴奋/惊讶/怀疑/生气/困倦/开心/好奇/困惑/无聊/得意/害羞/难过/大笑/害怕/调皮/庆祝/轨道/雷达/进度/诞生/哼唱/加载/听写/书写/发送/接收/上传/通知/警报/拖拽/弹跳/关机
- 每个状态关联原版表情池 + 专属动画（弹跳/倾斜/扫描/旋转/脉冲/故障）+ 持续循环动作

### 🎨 定制
- **10 种颜色**：可可棕/活力红/暖橙/琥珀/青绿/湖蓝/经典蓝/梦幻紫/桃粉/纯黑
- **8 种形状**：原始形态/鹅卵石/圆角方/胶囊/三角体/六边体/云朵/水滴
- **4 种身体部件**：双手/双脚/尾巴/天线
- **4 种趣味配饰**：草帽/眼镜/蝴蝶结/披风

### 🍮 果冻快捷动作
蹦跳 / 摇头 / 探头 / 捏脸 / 挤压 / 挥手

### 📸 分享卡
一键生成 1080×1440 PNG 分享卡，可下载或直接跳转 X 发布页。

### 🤖 其他
- 随机组合（一键随机颜色+形状+状态+装饰+动作）
- 自动巡演全部 39 种状态
- 鼠标滑动控制视线（3D 球面投影眼睛）+ 身体跟随微倾
- 眨眼（随机 2.2~5.2s，比原版固定 4.6s 更有生命感）

## 🧠 实现原理

- **表情 morph**：当前点集向目标点集逐点插值（弹簧阻尼动画）
- **3D 球面投影**：眼睛在球体表面移动（`asin` + longitude + perspective），支持转身
- **身体弹簧**：`a = (-k·(x−target) − c·v) / m` 每帧积分，四维（y/rot/scaleX/scaleY）
- **状态系统**：39 状态 × 表情池 × 一次性动作 × 持续循环动作 × 眨眼节奏
- **卡片堆叠**：`stackOrder` 循环队列 + CSS transform 错位 + 三风格 keyframe 动画
- **分享卡**：Canvas 2D 渲染 1080×1440（网格 + 部件 + 配饰 + 文案）
- 全部 `requestAnimationFrame` 驱动，本地运行零上传

## 🔧 开发与重建（README 没写会踩的坑）

### 直接使用（零构建）
仓库里提交的 `moodie.html` / `moodie-v1.html` 都是**完整可独立运行的单文件**，双击打开即玩，不需要任何构建步骤。

### 跑冒烟测试（先 extract，再 smoke）
`smoke_test.js` 运行时读取 `_check.js`，而 `_check.js` 是**本地临时产物、不入库**，由 `extract.py` 从 `moodie.html` 提取生成。clone 后直接跑 `node smoke_test.js` 会报"找不到 _check.js"——**不是测试坏了**，按顺序跑：

```powershell
python extract.py            # 从 moodie.html 提取全部 <script> 合并生成 _check.js（临时文件）
node --check _check.js       # 语法检查（可选）
node smoke_test.js           # 冒烟测试：25 表情 / 39 状态 / 持续动作 / 卡片堆叠 / 分享卡
```

### 从零重建 moodie.html（需要上游数据文件）
`build.py` 把 `original-data.js` 内嵌进 `_template.html` 生成 `moodie.html`。数据文件来自上游 [zhulin025/LaoA-GrokBot](https://github.com/zhulin025/LaoA-GrokBot) 仓库，脚本里硬编码的是作者本机路径：

```python
DATA_SRC = r'D:\temp\LaoA-GrokBot\original-data.js'
```

clone 上游仓库后，把 `DATA_SRC` 改成你的路径再 `python build.py`。**已提交的 `moodie.html` 无需重建**——只有改了 `_template.html` 逻辑需要重新生成时才需要这一步。
