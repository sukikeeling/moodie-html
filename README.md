# Moodie HTML · Grok 小脸复刻

一个会"活"的动画小表情，纯 HTML/CSS/JS 单文件实现，零依赖、无图片资源。灵感来自 [arhxam/moodie-react](https://github.com/arhxam/moodie-react)（Grok Bot 图标动画的开源变体）。

**直接打开 `moodie.html` 就能玩，双击即用。**

## ✨ 功能

- 😀 **16 种表情**：中性 / 开心 / 兴奋 / 困了 / 难过 / 担心 / 思考 / 喜欢 / 好奇 / 惊讶 / 专注 / 得意 / 头晕 / 平静 / 眨眼 / 警觉
- 🔷 **11 种形状**：圆 / 方圆 / 变形 / 卵石 / 菱 / 椭圆 / 三角 / 云朵 / 六边 / 方块 / 水滴，切换时平滑 morph
- 🌀 **弹簧物理**：表情/形状切换的弹性过渡（stiffness 210 / damping 22，与原版一致）
- 👀 **眨眼**：随机 2.6~6.2 秒眨一次
- 🖱️ **鼠标跟随**：眼睛追着鼠标看，身体微微倾斜
- 💥 **点击反应**：每种表情有专属反应（开心=弹跳、难过=压扁、头晕=旋转…）
- 🎭 **自动变脸**：开关打开后自动随机换表情
- 🎨 **外观定制**：身体/眼睛颜色、大小滑块

## 🎯 交互

| 操作 | 效果 |
|------|------|
| 左键点击 | 触发当前表情的反应动画 |
| 右键点击 | 循环切换形状 |
| 鼠标移动 | 眼睛注视跟随 + 身体倾斜 |

## 🧠 实现原理

与原版 Moodie 相同的核心算法，全部手写：

- **身体**：16 点闭环 → Catmull-Rom 三次贝塞尔曲线（11 种形状各 16 个点）
- **眼睛**：12 点超椭圆（x/y/宽/高/旋转/弧度/斜切 7 参数）
- **表情 morph**：眼睛 7 参数逐项弹簧插值
- **形状 morph**：16 点逐点弹簧插值
- **弹簧系统**：`a = (-k·(x−target) − c·v) / m` 每帧积分
- 渲染循环：`requestAnimationFrame`，全部路径每帧重算
