# Moodie HTML · Grok 小脸复刻（融合版）

一个会"活"的动画小表情——GrokBot 表情动作实验室的浏览器单文件版。纯 HTML/CSS/JS，零依赖、无图片资源，**双击打开 `moodie.html` 即玩**。

数据与动画核心移植自 [zhulin025/LaoA-GrokBot](https://github.com/zhulin025/LaoA-GrokBot)，UI 重新设计为深色主题。

## ✨ 功能

### 🎭 表情与状态
- **25 套原版表情**（Grok 原始坐标数据，逐点 morph 过渡）
- **39 种状态动作**（4 组分类）：睡眠/唤醒/待机/倾听/思考/搜索/工作/兴奋/惊讶/怀疑/生气/困倦/开心/好奇/困惑/无聊/得意/害羞/难过/大笑/害怕/调皮/庆祝/轨道/雷达/进度/诞生/哼唱/加载/听写/书写/发送/接收/上传/通知/警报/拖拽/弹跳/关机
- 每个状态关联原版表情池 + 专属动画（弹跳/倾斜/扫描/旋转/脉冲/故障）

### 🎨 定制
- **10 种颜色**：可可棕/活力红/暖橙/琥珀/青绿/湖蓝/经典蓝/梦幻紫/桃粉/纯黑
- **8 种形状**：原始形态/鹅卵石/圆角方/胶囊/三角体/六边体/云朵/水滴
- **4 种身体部件**：双手/双脚/尾巴/天线
- **4 种趣味配饰**：草帽/眼镜/蝴蝶结/披风

### 🍮 果冻快捷动作
蹦跳 / 摇头 / 探头 / 捏脸 / 挤压 / 挥手

### 📸 分享卡
一键生成 1080×1440 PNG 分享卡，可下载或直接跳转 X 发布页。

### 🤖 其他
- 随机组合（一键随机颜色+形状+状态+装饰+动作）
- 自动巡演全部 39 种状态
- 鼠标滑动控制视线（3D 球面投影眼睛）
- 眨眼（各状态独立节奏）

## 🎯 交互

| 操作 | 效果 |
|------|------|
| 在 GrokBot 区域滑动 | 眼睛跟随视线（球面投影） |
| 点击 GrokBot | 眨眼 |
| 点击表情/状态按钮 | 切换表情/状态 |
| 随机按钮 | 全随机组合 + 随机动作 |
| 自动巡演 | 依次巡演 39 种状态 |

## 🧠 实现原理

- **表情 morph**：当前点集向目标点集逐点插值（弹簧阻尼动画）
- **3D 球面投影**：眼睛在球体表面移动（`asin` + longitude + perspective），支持转身
- **状态系统**：39 状态 × 表情池 × 动作类 × 眨眼节奏 × 表情切换节奏
- **分享卡**：Canvas 2D 渲染 1080×1440（网格 + 部件 + 配饰 + 文案）
- 全部 `requestAnimationFrame` 驱动，本地运行零上传

## 🎭 双版本说明

| | **经典版 moodie-v1.html** | **融合版 moodie.html** |
|---|---|---|
| 定位 | 自己的特色 | 与原版一致 |
| 表情 | 16 种（参数化超椭圆） | 25 套（Grok 原始坐标） |
| 形状 | 11 种，平滑 morph | 8 种（clip-path） |
| 状态 | 点击反应 5 种 | 39 状态 + 持续循环动作 |
| 定制 | 颜色/大小 | 10 色/8 形/部件/配饰 |
| 分享卡 | ❌ | ✅ PNG 分享卡 |
| 动画核心 | Catmull-Rom 弹簧表演 | 坐标 morph + 球面投影 |
| 文件大小 | 30KB | 150KB |

两个版本都完整可用，双击各自打开即玩。
